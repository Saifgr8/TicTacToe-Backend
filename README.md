# Tic Tac Twist

**The classic game is just the beginning.**

Tic Tac Twist is a futuristic take on tic-tac-toe where the arena keeps expanding and clever play earns points you can use to unleash magic spells. Adapt your strategy as the board grows, outsmart your opponent, and turn a familiar contest into a twist-filled battle.

## The twist

- **A growing arena:** Start with a classic board, then watch the play space expand as the match unfolds.
- **Points with purpose:** Earn points through play and use them to access magical abilities.
- **Spell-powered strategy:** Spells can shake up the board and create new tactical opportunities. The exact spell set and rules can evolve as the game develops.
- **Classic at its heart:** Tic Tac Twist builds on the familiar goal of lining up your marks, with a larger, ever-changing arena to master.

## How to play

1. Take turns placing your mark on an available space.
2. Keep an eye on the expanding board and look for opportunities to line up your marks.
3. Earn points as you play and use them to cast spells.
4. Adapt your strategy—the board and the magic can change the match.

> Spell examples and specific match rules are part of the game design and may change as development continues.

## Built with

- Java 17
- Spring Boot 3.5
- Maven
- PostgreSQL

## Run locally

You will need Java 17 or later and a PostgreSQL database.

On Windows, run:

```powershell
.\mvnw.cmd spring-boot:run
```

On macOS or Linux, run:

```bash
./mvnw spring-boot:run
```

Configure the database connection for your local environment before starting the application. Check the project's application configuration for the required connection settings.

Tic Tac Twist is a work in progress. Gameplay rules, spell effects, and the expanding-board mechanics may continue to change.
